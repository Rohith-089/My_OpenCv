## Project 01 - Virtual Painter
Description
This project detects the color of a pen using HSV (Hue, Saturation, and Value) and tracks the movement of a hand holding that colored pen. As the user moves the pen in free air, the program draws lines corresponding to its movement, effectively creating a virtual painting system.

Technologies Used
OpenCV (for color detection and hand tracking)
Python (for implementation)

##Project 02 - Number Plate Detector
Description
This project detects number plates in uploaded images. It processes the image, identifies the number plate, and extracts the text using Tesseract OCR (pytesseract). The detected number plate details are then stored in a text file for further use.

Technologies Used
OpenCV (for image processing)
Pytesseract (for Optical Character Recognition)
Python (for implementation)
